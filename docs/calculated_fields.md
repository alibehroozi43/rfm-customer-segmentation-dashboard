# Tableau Calculated Fields

This document contains the calculated fields used to build the RFM Customer Segmentation Dashboard in Tableau.

## Dataset Fields

The dashboard uses the following original fields from the dataset:

- `Customer ID`
- `Order ID`
- `Order Date`
- `Sales`
- `Region`
- `Segment`
- `Category`
- `State`
- `City`

The exact field names may vary depending on the dataset.

---

# 1. Analysis Date

The analysis date is defined as one day after the latest order date in the dataset.

## Calculated Field Name

```text
Analysis Date
```

## Formula

```tableau
{ FIXED : DATEADD('day', 1, MAX([Order Date])) }
```

## Explanation

This calculation finds the maximum order date in the entire dataset and adds one day to it.

Using one day after the final transaction date ensures that the most recent customer has a Recency value of at least one day.

The expression:

```tableau
{ FIXED : ... }
```

calculates one global value for the entire dataset.

---

# 2. Recency

Recency represents the number of days since a customer's most recent purchase.

A lower Recency value indicates that the customer purchased more recently.

## Calculated Field Name

```text
Recency
```

## Formula

```tableau
DATEDIFF(
    'day',
    { FIXED [Customer ID] : MAX([Order Date]) },
    [Analysis Date]
)
```

## Explanation

The following part finds the latest order date for each customer:

```tableau
{ FIXED [Customer ID] : MAX([Order Date]) }
```

Then, `DATEDIFF` calculates the number of days between the customer's latest purchase and the analysis date.

---

# 3. Frequency

Frequency represents the number of unique orders made by each customer.

## Calculated Field Name

```text
Frequency
```

## Formula

```tableau
{ FIXED [Customer ID] : COUNTD([Order ID]) }
```

## Explanation

`COUNTD` counts distinct Order IDs.

The FIXED expression ensures that Tableau calculates the number of orders separately for every customer.

---

# 4. Monetary

Monetary represents the total amount spent by each customer.

## Calculated Field Name

```text
Monetary
```

## Formula

```tableau
{ FIXED [Customer ID] : SUM([Sales]) }
```

## Explanation

This calculation adds all sales generated by each customer.

Customers with higher Monetary values have generated more revenue.

---

# 5. R Score

The R Score divides customers into five groups based on Recency.

Because a lower Recency value is better, customers with the lowest Recency receive the highest score.

## Calculated Field Name

```text
R Score
```

## Formula

```tableau
IF [Recency] <= { FIXED : PERCENTILE([Recency], 0.2) } THEN 5

ELSEIF [Recency] <= { FIXED : PERCENTILE([Recency], 0.4) } THEN 4

ELSEIF [Recency] <= { FIXED : PERCENTILE([Recency], 0.6) } THEN 3

ELSEIF [Recency] <= { FIXED : PERCENTILE([Recency], 0.8) } THEN 2

ELSE 1
END
```

## Score Interpretation

| R Score | Interpretation |
|---:|---|
| 5 | Purchased very recently |
| 4 | Purchased recently |
| 3 | Average recency |
| 2 | Has not purchased recently |
| 1 | Has been inactive for a long time |

# 8. RFM Score

The RFM Score combines the individual Recency, Frequency, and Monetary scores.

## Calculated Field Name

```text
RFM Score
```

## Formula

```tableau
STR([R Score])
+
STR([F Score])
+
STR([M Score])
```

## Explanation

The `STR` function converts each numeric score into text.

For example:

```text
R Score = 5
F Score = 4
M Score = 3
```

The resulting RFM Score is:

```text
543
```

This is a categorical RFM code rather than a mathematical sum.

---

# 9. Total RFM Score

This field calculates the sum of the three individual scores.

## Calculated Field Name

```text
Total RFM Score
```

## Formula

```tableau
[R Score] + [F Score] + [M Score]
```

## Explanation

Unlike the text-based RFM Score, this field produces a numeric value between 3 and 15.

A higher value generally indicates a more valuable customer.

---

# 10. RF Score

This field combines Recency and Frequency scores.

## Calculated Field Name

```text
RF Score
```

## Formula

```tableau
STR([R Score]) + STR([F Score])
```

## Explanation

The RF Score can be used when customer segmentation is mainly based on recency and frequency.

For example:

```text
R Score = 5
F Score = 4
RF Score = 54
```

# 11. RFM Segment

This calculated field assigns each customer to a behavioral segment based primarily on Recency and Frequency scores.

## Calculated Field Name

```text
RFM Segment
```

## Formula

```tableau
IF [R Score] >= 4
AND [F Score] >= 4
THEN "Champions"

ELSEIF [R Score] >= 4
AND [F Score] = 3
THEN "Potential Loyalists"

ELSEIF [R Score] >= 4
AND [F Score] <= 2
THEN "New Customers"

ELSEIF [R Score] = 3
AND [F Score] >= 4
THEN "Loyal Customers"

ELSEIF [R Score] = 3
AND [F Score] = 3
THEN "Promising"

ELSEIF [R Score] = 3
AND [F Score] <= 2
THEN "Needs Attention"

ELSEIF [R Score] = 1
AND [F Score] = 1
THEN "Lost"

ELSEIF [R Score] <= 2
AND [F Score] >= 4
THEN "Cannot Lose Them"

ELSEIF [R Score] <= 2
AND [F Score] = 3
THEN "At Risk"

ELSE "Lost"
END
```

## Segment Interpretation

| Segment | Description |
|---|---|
| Champions | Recent, frequent, and highly engaged customers |
| Potential Loyalists | Recent customers with moderate purchase frequency |
| New Customers | Recently acquired customers with limited purchase history |
| Loyal Customers | Customers with consistent and frequent purchases |
| Promising | Customers showing moderate engagement |
| Needs Attention | Customers whose engagement may be declining |
| Cannot Lose Them | Previously valuable customers who have become inactive |
| At Risk | Customers at risk of becoming inactive or leaving |
| Lost | Customers with very low recency and frequency performance |

# Notes About FIXED LOD Expressions

FIXED Level of Detail expressions calculate values at a specified level, regardless of the dimensions currently displayed in the visualization.

For example:

```tableau
{ FIXED [Customer ID] : SUM([Sales]) }
```

calculates total sales separately for every customer.

The result remains fixed at the customer level, even when additional dimensions are added to the worksheet.

However, FIXED calculations may not respond to ordinary dimension filters unless those filters are added to Context.

To make a filter affect FIXED calculations:

1. Right-click the filter.
2. Select `Add to Context`.
3. The filter will turn gray in the Filters shelf.

# RFM Methodology

RFM analysis evaluates customers using three behavioral dimensions:

- **Recency:** How recently the customer made a purchase.
- **Frequency:** How often the customer purchases.
- **Monetary:** How much money the customer has spent.

Each customer receives a score between 1 and 5 for every dimension.

Customers are then grouped into meaningful business segments that can support:

- Customer retention strategies
- Loyalty campaigns
- Reactivation campaigns
- Personalized marketing
- Revenue analysis
- Customer prioritization
